# Uso de Inteligencia Artificial

Durante el desarrollo de este proyecto se utilizo chat gpt

## Herramienta utilizada

- ChatGPT de OpenAI.
- copilot

## Uso realizado

La inteligencia artificial se utilizó para:

- Orientar el orden de desarrollo de algunas funcionalidades.
- Resolver dudas específicas sobre Django y Git.
- Apoyar en la identificación y corrección de algunos errores.
- Guiar la implementación de validaciones como RUT y control de stock.
- Explicar algunos fragmentos de código para facilitar su comprensión.
